## 🎵 lx2MF 使用说明
将 LXMusic 歌单转换为 MusicFree 可导入格式的工具。

## ✅ 当前功能支持
支持 LXMusic 歌单 → MusicFree JSON 格式转换

仅支持 单个歌单文件（.lxmc）转换

仅支持 部分音源，请确保 MusicFree 已安装对应插件


## 📌 使用步骤
在 LXMusic 中，右键歌单 → 导出为文件（生成 .lxmc 文件）

将 .lxmc 文件 拖入 lx2MF.exe 可执行文件

程序将自动生成一个 .json 文件

在 MusicFree 中导入该 .json 文件，即可完成迁移


## 🚧 注意事项
当前版本仅支持 LX → MusicFree 单向导入

后续版本将考虑支持 双向转换（MusicFree → LX）

请确保 .lxmc 文件格式正确，文件名不含特殊字符

若导入失败，请检查 MusicFree 是否已安装对应音源插件
